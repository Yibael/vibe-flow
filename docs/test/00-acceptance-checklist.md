# 验收清单 00：个人净值管理系统

## 基础验证

- `bun run typecheck` 通过。
- `bun run lint` 通过。
- `bun run build` 通过。
- 数据库文件可自动创建。
- 重启应用后数据仍存在。

## 资产负债项目

- 可以新增资产项目。
- 可以新增负债项目。
- 资产和负债金额都按正数录入。
- 金额为 0 可以保存。
- 负数金额不能保存。
- 空名称不能保存。
- 资产类型不能选择负债类别。
- 负债类型不能选择资产类别。
- 可以编辑项目名称、类型、类别、金额和备注。
- 可以归档项目。
- 归档项目不再计入当前汇总。
- 归档项目不会被物理删除。

## 当前净值

- 总资产等于未归档资产项目金额之和。
- 总负债等于未归档负债项目金额之和。
- 净资产等于总资产减总负债。
- 净资产可以为负数。
- 没有未归档项目时，汇总显示 0。
- 分类汇总中资产和负债分开展示。
- 分类占比不会除以 0。

## 每日快照

- 新增项目后自动创建或更新今日快照。
- 编辑项目后自动更新今日快照。
- 归档项目后自动更新今日快照。
- 手动保存今日快照可成功。
- 同一日期不会产生重复快照。
- 补录历史日期快照可成功。
- 补录已存在日期会覆盖该日期快照。
- 无未归档项目时可保存 0 值快照。
- 删除快照需要确认。
- 删除快照不会影响资产负债项目。
- 删除快照后分类明细同步删除。

## 看板

- 首页显示当前净资产、总资产、总负债。
- 存在上一快照时显示净值变化。
- 没有上一快照时显示“暂无对比”，不是 0。
- 趋势图按快照日期升序展示。
- 快照少于两条时趋势图区显示空状态。
- 最近更新项目只包含未归档项目。
- 最近更新项目按更新时间倒序排列。
- 无负债时负债组成显示空状态。

## 页面与交互

- `/` 可访问。
- `/accounts` 可访问。
- `/snapshots` 可访问。
- 新增/编辑项目弹窗包含标题。
- 归档确认框包含标题。
- 补录快照弹窗包含标题。
- 删除快照确认框包含标题。
- 表单错误显示在对应字段附近。
- 保存失败时弹窗保持打开。
- 移动端无文字重叠。
- 表格在窄屏可横向滚动。

## 数据库

- `account_items` 表存在。
- `net_worth_snapshots` 表存在。
- `snapshot_category_breakdowns` 表存在。
- `schema_migrations` 表存在。
- `amount_cents` 使用整数分存储。
- `snapshot_date` 唯一。
- 删除 `net_worth_snapshots` 记录后，对应 `snapshot_category_breakdowns` 级联删除。
