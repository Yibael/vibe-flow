# PRD 01：当前净值管理

## 背景

本系统是一个面向个人使用的小型净值管理工具。第一阶段聚焦于手动维护当前资产和负债余额，并汇总展示用户当前净值。

系统不是完整记账软件、投资交易分析工具或多人财务平台。它优先解决的问题是：用户当前有多少净资产，以及这些资产和负债大致分布在哪些类别中。

## 目标

交付一个本机运行的本地 Web 应用，支持单个用户创建、编辑、归档并查看当前资产和负债项目。所有数据存储在轻量 SQLite 数据库中。

## 目标用户

- 单个个人用户。
- 用户在自己的电脑上管理个人财务。
- 用户手动录入所有资产和负债余额。
- 用户需要一个简单的本地工具，不需要云同步或自动账户聚合。

## 用户故事

- 作为用户，我可以新增一个资产项目，使其计入总资产。
- 作为用户，我可以新增一个负债项目，使其计入总负债。
- 作为用户，我可以在余额变化后编辑项目金额。
- 作为用户，我可以归档一个不再计入当前净值的项目。
- 作为用户，我可以快速看到总资产、总负债和净资产。
- 作为用户，我可以按类别查看资产和负债的大致分布。

## 功能需求

### 资产与负债项目

系统必须支持项目的新建、编辑、列表查看和归档。

每个项目必须包含：

- 名称。
- 类别。
- 类型：资产或负债。
- 人民币金额。
- 备注，选填。
- 创建时间。
- 更新时间。
- 归档时间，未归档时为空。

支持的资产类别：

- 现金。
- 银行账户。
- 投资。
- 房产。
- 车辆。
- 其他资产。

支持的负债类别：

- 贷款。
- 信用卡。
- 其他负债。

所有项目金额都以人民币正数录入。该金额增加还是减少净值，由项目类型决定。

### 当前净值汇总

系统必须计算并展示：

- 总资产：所有未归档资产项目金额之和。
- 总负债：所有未归档负债项目金额之和。
- 净资产：总资产减总负债。

已归档项目不得计入当前汇总。

### 分类汇总

系统必须展示未归档项目的分类汇总。

资产类别和负债类别必须分开展示，不能将负债类别混入资产配置中。

### 本地持久化

系统必须使用本地 SQLite 数据库存储数据。

浏览器只作为用户界面。数据读写应由本地应用后端处理，例如 Next.js Server Actions、Route Handlers，或应用内其他服务端逻辑。

## 数据模型

### AccountItem

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 稳定唯一标识 |
| name | string | 是 | 用户可见的项目名称 |
| category | string | 是 | 一个受支持的类别 |
| kind | string | 是 | `asset` 或 `liability` |
| amountCents | number | 是 | 人民币金额，单位为分，非负数，可以为 0 |
| note | string | 否 | 备注 |
| createdAt | datetime | 是 | 创建时间 |
| updatedAt | datetime | 是 | 最后更新时间 |
| archivedAt | datetime | 否 | 未归档时为空 |

## 页面与交互

### 主页面

首屏必须优先展示当前净值信息：

- 净资产。
- 总资产。
- 总负债。
- 分类分布。
- 当前未归档项目列表。

### 项目表单

项目表单必须支持：

- 创建资产或负债。
- 根据项目类型选择对应类别。
- 输入人民币金额。
- 输入可选备注。
- 保存修改。
- 取消并不改变数据。

### 归档流程

用户必须能够归档项目。

归档后必须：

- 设置 `archivedAt`。
- 将该项目从当前净值计算中移除。
- 保留该项目的已存储数据。

第一阶段不要求支持物理删除。

## 边界条件

- 净资产可以为负数。
- 项目金额可以为 0。
- 所有金额只支持人民币。
- 不允许保存负数金额。
- 不允许保存空名称。
- 已归档项目不影响当前汇总。
- 没有任何未归档项目时，总额展示为 0，项目列表展示空状态。
- 第一阶段不要求保留历史余额。

## 非目标范围

- 不做登录。
- 不做云同步。
- 不做多人或家庭共享。
- 不做银行、券商、基金、汇率等外部数据同步。
- 不做流水记账。
- 不做投资收益分析。
- 不要求每日快照或趋势图。
- 不做备份和恢复。

## 验收标准

- 用户可以新增资产项目，并看到总资产增加。
- 用户可以新增负债项目，并看到总负债增加。
- 净资产始终等于总资产减总负债。
- 编辑项目金额后，当前汇总立即变化。
- 归档项目后，该项目不再计入当前汇总，但记录仍保留。
- 分类汇总只包含未归档项目。
- 空名称、负数金额等非法输入不能保存。
- 关闭并重新打开本地应用后，SQLite 中的数据仍然存在。
