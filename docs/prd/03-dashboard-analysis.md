# PRD 03：净值看板与分析

## 背景

本系统是一个面向个人使用的小型净值管理工具。本阶段聚焦于看板体验：将用户手动维护的余额和已保存快照转化为清晰的净值总览。

看板应优先呈现当前净值、近期变化、历史趋势和分类分布。它是一个可反复使用的财务工具界面，而不是营销落地页。

## 目标

交付一个净值看板，使用户能够快速理解当前净资产、资产负债结构和历史变化。

本阶段必须可以独立实现。如果单独交付，可以使用已有 SQLite 数据，也可以实现一个最小本地数据层来提供资产负债项目和快照数据。

## 目标用户

- 单个个人用户。
- 用户在自己的电脑上管理个人财务。
- 用户需要简洁总览，而不是详细会计报表。
- 用户手动维护余额和快照。

## 用户故事

- 作为用户，我打开应用后可以立即看到当前净资产。
- 作为用户，我可以将当前净资产与最近一次历史快照进行比较。
- 作为用户，我可以查看净值随时间变化的趋势。
- 作为用户，我可以查看资产和负债按类别的组成。
- 作为用户，我可以识别最近更新过的项目。
- 作为用户，我可以在没有数据或数据不足时理解页面状态。

## 功能需求

### 关键指标

看板必须展示：

- 当前净资产。
- 总资产。
- 总负债。
- 相比上一个快照的变化，存在可比较快照时展示。

当前净资产必须由未归档资产负债项目计算得出。历史对比使用当前日期之前最近的一条快照，或最新可用快照日期之前最近的一条快照。

### 趋势图

看板必须基于已保存快照展示净值趋势图。

趋势图必须满足：

- 横轴为快照日期。
- 纵轴为人民币净资产。
- 支持正数和负数净资产。
- 当快照少于两条时展示空状态。

### 分类组成

看板必须展示当前未归档项目的分类分布。

分类视图必须满足：

- 资产和负债分开展示。
- 展示类别名称和类别总金额。
- 当对应总额大于 0 时，展示类别占比。
- 没有数据的类别需要优雅处理。

### 最近更新项目

看板必须展示最近更新的未归档项目。

每行至少包含：

- 名称。
- 类别。
- 类型。
- 人民币金额。
- 更新时间。

列表按更新时间倒序排列。

### 空状态

看板必须为以下情况提供清晰空状态：

- 没有任何资产负债项目。
- 没有任何快照。
- 只有一条快照，无法形成趋势对比。
- 没有负债。

## 数据模型

### AccountItem

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 稳定唯一标识 |
| name | string | 是 | 用户可见的项目名称 |
| category | string | 是 | 受支持的类别 |
| kind | string | 是 | `asset` 或 `liability` |
| amountCents | number | 是 | 人民币金额，单位为分，非负数，可以为 0 |
| archivedAt | datetime | 否 | 未归档时为空 |
| updatedAt | datetime | 是 | 用于最近更新排序 |

### NetWorthSnapshot

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 稳定唯一标识 |
| snapshotDate | date | 是 | 唯一本地日期 |
| totalAssetsCents | number | 是 | 保存时的总资产，单位为分 |
| totalLiabilitiesCents | number | 是 | 保存时的总负债，单位为分 |
| netWorthCents | number | 是 | 保存时的净资产，单位为分 |
| updatedAt | datetime | 是 | 最后更新时间 |

### SnapshotCategoryBreakdown

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 稳定唯一标识 |
| snapshotId | string | 是 | 所属快照 ID |
| kind | string | 是 | `asset` 或 `liability` |
| category | string | 是 | 受支持的类别 |
| amountCents | number | 是 | 该分类在快照中的金额，单位为分 |

## 页面与交互

### 看板布局

首屏应优先支持快速扫读和重复使用：

- 顶部指标区展示净资产、总资产、总负债和变化。
- 趋势图区展示净值历史。
- 分类组成区展示资产和负债分布。
- 最近更新列表展示活跃项目。

看板不应设计成营销式首屏，而应作为紧凑的个人财务工具界面。

### 导航

如果系统中存在项目管理或快照管理页面，看板可以链接到这些页面。即使这些页面不属于本阶段交付范围，看板本身也必须能够独立展示有效信息。

### 格式化

所有货币值必须按人民币格式展示。

只有当分母大于 0 时才展示百分比。

## 边界条件

- 净资产可以为负数。
- 总负债可以为 0。
- 分类占比不得除以 0。
- 已归档项目不得出现在当前指标、当前分类组成或最近活跃项目列表中。
- 趋势图必须能处理快照日期不连续的情况。
- 看板不得修改资产负债项目或快照数据。
- 没有可比较的历史快照时，变化值应展示为不可用，而不是 0。

## 非目标范围

- 不要求新增或编辑资产负债项目。
- 不要求新增或编辑快照。
- 不做流水记账。
- 不做投资收益分析。
- 不做预测或目标管理。
- 不做提醒或预警。
- 不做备份和恢复。

## 验收标准

- 看板能够基于未归档项目展示当前净资产、总资产和总负债。
- 存在历史快照时，看板能够展示相对上一快照的变化。
- 不存在历史快照时，看板不会展示误导性的 0 变化。
- 趋势图按日期顺序渲染已保存快照。
- 快照数据不足时，趋势图区展示空状态。
- 资产分类组成和负债分类组成分开展示。
- 分类占比计算正确，且不会出现除以 0。
- 最近更新项目按更新时间倒序排列。
- 已归档项目不会出现在任何当前看板视图中。
