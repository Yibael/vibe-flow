# PRD 02：每日净值快照

## 背景

本系统是一个面向个人使用的小型净值管理工具。本阶段交付每日净值快照和历史补录能力，让用户可以追踪净值随时间的变化。

系统以用户手动维护的当前资产和负债余额作为快照生成来源。不要求流水账，也不要求自动同步金融账户。

## 目标

交付每日快照生成、当日快照自动更新、历史日期补录和 SQLite 本地存储能力。

本阶段必须可以独立实现。如果单独交付，也应包含生成和查看快照所需的最小资产负债余额管理能力。

## 目标用户

- 单个个人用户。
- 用户在自己的电脑上管理个人财务。
- 用户手动维护当前资产和负债余额。
- 用户希望查看净值历史，而不是记录完整会计流水。

## 用户故事

- 作为用户，我可以在更新余额后保存今日净值快照。
- 作为用户，我修改项目余额后，今日快照可以自动更新。
- 作为用户，我可以为过去某个日期补录一条快照。
- 作为用户，我可以查看已经保存的快照列表。
- 作为用户，我可以在确认后删除错误的快照。

## 功能需求

### 余额来源

快照由当前未归档的资产和负债项目生成。

每个项目至少需要包含：

- 名称。
- 类别。
- 类型：资产或负债。
- 人民币金额。
- 归档状态。

只有未归档项目会参与快照计算。

### 快照计算

针对指定日期，系统必须计算：

- 人民币总资产。
- 人民币总负债。
- 人民币净资产。
- 分类汇总结构化数据。

净资产等于总资产减总负债。

### 当日快照自动更新

当用户创建、编辑或归档资产负债项目时，系统必须自动创建或更新当前本地日期的快照。

如果当前日期已经存在快照，则更新已有快照，不得创建重复快照。

### 历史补录

用户必须能够选择一个历史日期并保存该日期的快照。

历史补录使用保存时当前录入的未归档余额进行汇总。系统不通过流水反推历史账户余额。

如果所选日期已经存在快照，再次保存时必须更新已有快照，不得创建重复快照。

### 快照列表

系统必须提供快照列表，展示：

- 快照日期。
- 总资产。
- 总负债。
- 净资产。
- 最后更新时间。

列表默认按快照日期倒序排列。

### 快照删除

用户可以在明确确认后删除快照。

删除快照不得修改当前资产或负债项目。

## 数据模型

### AccountItem

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 稳定唯一标识 |
| name | string | 是 | 用户可见的项目名称 |
| category | string | 是 | 受支持的类别 |
| kind | string | 是 | `asset` 或 `liability` |
| amountCny | number | 是 | 人民币金额，非负数，可以为 0 |
| archivedAt | datetime | 否 | 未归档时为空 |
| createdAt | datetime | 是 | 创建时间 |
| updatedAt | datetime | 是 | 最后更新时间 |

### NetWorthSnapshot

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 稳定唯一标识 |
| snapshotDate | date | 是 | 唯一本地日期 |
| totalAssetsCny | number | 是 | 未归档资产项目汇总 |
| totalLiabilitiesCny | number | 是 | 未归档负债项目汇总 |
| netWorthCny | number | 是 | 总资产减总负债 |
| categoryBreakdownJson | string | 是 | 序列化后的分类汇总 |
| createdAt | datetime | 是 | 创建时间 |
| updatedAt | datetime | 是 | 最后更新时间 |

`snapshotDate` 必须具备唯一约束。

## 页面与交互

### 快照操作区

用户必须能够：

- 查看今日快照是否已存在。
- 保存或更新今日快照。
- 选择历史日期并保存补录快照。

### 快照列表

列表必须展示已保存快照，并支持在确认后删除单条快照。

### 操作反馈

系统应清晰提示快照已创建、已更新或已删除。

## 边界条件

- 快照日期使用本机系统日期。
- 同一个日期只能有一条快照。
- 重复保存同一日期时覆盖该日期已有快照值。
- 历史补录不推断过去余额。
- 已归档项目不参与新生成的快照。
- 除当日项目变更触发当日快照更新外，既有历史快照不会因后续项目归档或金额修改而自动重算。
- 净资产可以为负数。
- 所有金额只支持人民币。
- 没有任何未归档项目时，仍可保存总资产为 0、总负债为 0、净资产为 0 的快照。

## 非目标范围

- 不做流水记账。
- 不自动重建历史余额。
- 不做定时后台任务。
- 不做投资收益计算。
- 不做外部账户或汇率同步。
- 不做备份和恢复。

## 验收标准

- 新增或编辑未归档项目时，系统自动创建或更新今日快照。
- 归档项目时，系统自动更新今日快照。
- 同一日期不会出现重复快照。
- 用户可以补录历史日期快照。
- 补录已存在日期时，会更新该日期快照。
- 用户可以按日期倒序查看快照列表。
- 删除快照必须二次确认，且不会影响资产负债项目。
- 重启本地应用后，SQLite 中的快照数据仍然存在。
