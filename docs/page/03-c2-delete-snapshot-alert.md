# 子节点 03-c2：删除快照确认框

## 节点类型

AlertDialog。

## 节点目标

用于确认删除一条净值快照。删除快照只影响历史趋势数据，不影响资产负债项目。

## 触发来源

在 `docs/page/03-snapshots-page.md` 的快照列表中点击某条快照的 `删除` 按钮。

## 打开条件

- 用户选择了一条已存在快照。

## 弹窗标题

`确认删除快照？`

AlertDialog 必须包含 `AlertDialogTitle`。

## 内容描述

正文应明确说明：

- 删除后，该日期不会再出现在净值趋势中。
- 删除不会影响当前资产负债项目。
- 删除不会影响其他日期快照。

正文中展示快照摘要：

- 快照日期。
- 总资产。
- 总负债。
- 净资产。

## 主要操作

操作按钮：

- `取消`。
- `确认删除`。

取消：

- 关闭确认框。
- 不改变数据。

确认删除：

- 调用删除快照 Server Action。
- 提交中禁用按钮。
- 成功后关闭确认框并刷新快照列表。

## 成功反馈

删除成功后：

- 显示 toast：`快照已删除`。
- 快照列表刷新。
- 如果删除后无快照，页面展示空状态。

## 错误状态

- 快照不存在：显示 `快照不存在或已被删除`。
- 数据库写入失败：显示 `删除失败，请稍后重试`。
- 错误发生时确认框保持打开，用户可取消或重试。

## shadcn/ui 组件清单

- `AlertDialog`
- `Button`
- `Badge`
- `sonner`

## 移动端适配

- 按钮在窄屏下可上下排列。
- 快照摘要金额允许换行。
- 日期和金额不得溢出弹窗。

## 验收标准

- 点击删除后显示确认框。
- 确认框展示快照日期和金额摘要。
- 点击取消不会删除快照。
- 点击确认后删除对应快照。
- 删除快照不会影响资产负债项目。
- 删除失败时显示错误且不关闭确认框。
