# 子节点 03-c1：补录快照弹窗

## 节点类型

Dialog。

## 节点目标

用于为指定历史日期保存一条净值快照。快照内容基于提交时当前未归档资产负债项目汇总生成。

## 触发来源

- 在 `docs/page/03-snapshots-page.md` 点击 `补录快照`。
- 在无快照空状态中点击 `补录历史快照`。

## 打开条件

- 用户点击补录入口。
- 系统可以读取当前未归档资产负债项目。

## 弹窗标题

`补录历史快照`

Dialog 必须包含 `DialogTitle`。

## 内容说明

弹窗正文需要明确说明：

- 补录快照会使用当前录入的资产负债余额。
- 系统不会通过流水反推过去余额。
- 如果所选日期已有快照，本次保存会覆盖该日期快照。

## 表单字段

### 快照日期

控件：

- 第一版可使用 `Input type="date"`。
- 如果安装并使用 shadcn Calendar，则用 `Calendar` + `Popover`。

规则：

- 必填。
- 格式为 `YYYY-MM-DD`。
- 允许选择过去日期。
- 允许选择今日日期；选择今日日期等同更新今日快照。

### 当前汇总预览

该区域展示提交时将被保存的值：

- 总资产。
- 总负债。
- 净资产。

说明：

- 预览值来自当前未归档项目。
- 如果没有未归档项目，三项均为 0。

shadcn/ui 组件建议：

- `Card` 或紧凑列表。
- `Badge` 用于提示“将覆盖已有快照”。

## 覆盖提示

如果用户选择的日期已经存在快照：

- 在表单中显示提示：`该日期已有快照，保存后将覆盖原记录`。
- 不需要额外二次确认。

## 主要操作

底部操作区：

- `取消`。
- `保存快照`。

取消：

- 关闭弹窗。
- 不保存数据。

保存：

- 校验日期。
- 调用补录快照 Server Action。
- 提交中禁用按钮。
- 成功后关闭弹窗并刷新快照列表。

## 校验反馈

- 日期为空：`请选择快照日期`。
- 日期格式错误：`请输入有效日期`。
- 保存失败：`快照保存失败，请稍后重试`。

错误发生时弹窗保持打开。

## 成功反馈

保存成功后：

- 关闭弹窗。
- 快照列表刷新。
- 显示 toast：
  - 新增日期：`快照已保存`。
  - 覆盖日期：`快照已更新`。

## shadcn/ui 组件清单

- `Dialog`
- `Field`
- `Input`
- 可选 `Calendar`
- 可选 `Popover`
- `Button`
- `Badge`
- `sonner`

## 移动端适配

- 表单字段纵向排列。
- 日期选择控件不能超出弹窗宽度。
- 汇总预览使用单列展示。

## 验收标准

- 用户可以选择日期并保存快照。
- 日期为空时无法保存。
- 已存在日期保存时覆盖原快照。
- 补录不会修改资产负债项目。
- 保存成功后关闭弹窗并刷新列表。
- 保存失败时弹窗保持打开并显示错误。
