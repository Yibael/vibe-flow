# 页面 01：净值看板页

## 页面目标

净值看板页是用户打开系统后的默认首页，用于快速理解当前净资产、资产负债结构、净值历史趋势和最近更新项目。

本页面只负责展示和导航，不直接修改资产负债项目或快照数据。

## 路由建议

`/`

## 用户进入方式

- 用户打开本地应用后默认进入。
- 其他页面顶部导航中的“看板”入口进入。

## 页面整体布局

页面采用工具型仪表盘布局，不使用营销式 Hero。

桌面端布局从上到下为：

1. 顶部应用栏。
2. 页面标题与主要操作入口。
3. 关键指标区。
4. 趋势图与分类组成区。
5. 最近更新项目区。

移动端布局改为单列纵向排列，所有区域保持相同顺序。

## 顶部应用栏

顶部应用栏固定在页面内容上方，不要求吸顶。

内容包括：

- 左侧：产品名称“个人净值”。
- 中间或右侧：页面导航。
  - 看板。
  - 资产管理。
  - 快照管理。
- 右侧：主题切换按钮，如果系统已提供暗色模式能力。

shadcn/ui 组件建议：

- `Button` 用于导航入口或主题切换。
- `Separator` 用于应用栏与页面主体分隔。

交互说明：

- 当前页面导航项应有清晰选中状态。
- 导航使用普通页面跳转，不打开弹窗。
- 图标使用 lucide，并在 Button 内设置 `data-icon`。

## 页面标题区

标题区位于应用栏下方。

内容包括：

- 主标题：`净值看板`。
- 辅助说明：`查看当前净值、历史趋势和资产负债结构`。
- 右侧快捷入口：
  - `管理资产`，跳转 `/accounts`。
  - `管理快照`，跳转 `/snapshots`。

shadcn/ui 组件建议：

- `Button` 用于快捷入口。

视觉要求：

- 标题不使用超大 Hero 字号。
- 文案应紧凑，适合后台工具。
- 移动端快捷入口换行排列，按钮不能挤压文本。

## 关键指标区

关键指标区使用 4 个 Card 横向排列，移动端改为两列或单列。

指标包括：

1. 当前净资产。
2. 总资产。
3. 总负债。
4. 较上一快照变化。

每个指标 Card 内容：

- 指标名称。
- 指标金额。
- 辅助说明。
- 可选图标。

当前净资产 Card：

- 金额为当前未归档资产总额减当前未归档负债总额。
- 净资产允许为负数。
- 金额展示人民币格式。

总资产 Card：

- 展示所有未归档资产项目金额之和。

总负债 Card：

- 展示所有未归档负债项目金额之和。
- 若总负债为 0，辅助说明显示“当前无负债”。

较上一快照变化 Card：

- 如果存在可比较快照，展示变化金额。
- 如果不存在可比较快照，展示“暂无对比”。
- 不得将无对比数据展示为 0。

shadcn/ui 组件建议：

- `Card`、`CardHeader`、`CardTitle`、`CardDescription`、`CardContent`。
- `Badge` 用于“上升”“下降”“暂无对比”等状态。

## 趋势图区

趋势图区展示净值历史趋势。

数据来源：

- `net_worth_snapshots`。
- 按快照日期升序展示。

图表内容：

- 横轴：快照日期。
- 纵轴：净资产，人民币格式。
- 支持正数和负数。
- 日期不连续时仍按已有快照点连接。

交互：

- 鼠标悬停显示 Tooltip。
- Tooltip 展示日期和净资产金额。
- 图表不提供数据编辑入口。

空状态：

- 没有快照时，展示“暂无快照数据”。
- 只有一条快照时，展示“至少需要两条快照才能形成趋势”。

shadcn/ui 组件建议：

- `Card` 包裹图表。
- `Chart` 包装 Recharts。
- `Empty` 展示空状态。
- `Skeleton` 可用于加载占位。

## 分类组成区

分类组成区与趋势图同层展示。桌面端可以放在趋势图区右侧或下方双列区域，移动端置于趋势图之后。

内容分为两个部分：

1. 资产组成。
2. 负债组成。

资产组成：

- 展示每个资产类别的名称、金额、占总资产比例。
- 当总资产为 0 时，不展示百分比，显示空状态。

负债组成：

- 展示每个负债类别的名称、金额、占总负债比例。
- 当总负债为 0 时，展示“当前无负债”。

展示形式：

- 可以使用条形列表。
- 每行包含类别名、金额、百分比。
- 百分比条只使用语义颜色，不硬编码强烈颜色。

shadcn/ui 组件建议：

- `Card`。
- `Badge`。
- `Separator`。
- `Empty`。

边界：

- 分类占比不得除以 0。
- 资产和负债不得混在同一个占比集合中。

## 最近更新项目区

最近更新项目区展示未归档资产负债项目。

默认展示最近 5 到 10 条，按更新时间倒序排列。

表格列：

- 名称。
- 类型。
- 类别。
- 金额。
- 更新时间。

交互：

- 点击“查看全部”跳转 `/accounts`。
- 本页面不提供编辑和归档操作。

shadcn/ui 组件建议：

- `Card`。
- `Table`。
- `Badge`。
- `Button`。
- `Empty`。

空状态：

- 没有任何未归档项目时，显示“暂无资产负债项目”。
- 提供 `去添加` 按钮，跳转 `/accounts`。

## 数据来源

页面需要读取：

- 当前总资产。
- 当前总负债。
- 当前净资产。
- 上一快照净资产。
- 快照趋势列表。
- 资产分类汇总。
- 负债分类汇总。
- 最近更新项目列表。

数据由服务端读取 SQLite 后传入页面组件。Zustand 不作为本页面财务数据来源。

## 错误状态

如果数据库读取失败：

- 页面主体展示错误提示。
- 提供“重试”按钮。
- 不显示伪造的 0 数据。

如果部分数据缺失：

- 当前指标可显示的部分正常展示。
- 趋势或最近项目区域单独显示空状态。

## 移动端适配

- 页面整体为单列布局。
- 指标 Card 最多两列，窄屏单列。
- 图表高度固定在可读范围内，避免被压扁。
- 表格在窄屏可横向滚动，不能挤压文本。
- 顶部导航可改为紧凑按钮组。

## shadcn/ui 组件清单

- `Button`
- `Card`
- `Chart`
- `Table`
- `Badge`
- `Empty`
- `Skeleton`
- `Separator`
- 可选：`Tabs`

## 验收标准

- 打开 `/` 后能看到当前净资产、总资产、总负债。
- 无上一快照时变化值显示“暂无对比”。
- 趋势图在快照少于两条时显示空状态。
- 资产组成和负债组成分开展示。
- 无负债时负债组成显示空状态。
- 最近更新项目不包含已归档项目。
- 页面中没有任何数据修改弹窗。
- 移动端无文字重叠或按钮溢出。
