# 子节点 02-c2：归档项目确认框

## 节点类型

AlertDialog。

## 节点目标

用于确认归档一个资产或负债项目。归档后该项目不再计入当前净值，但历史记录保留。

## 触发来源

在 `docs/page/02-accounts-page.md` 的项目表格中点击某个未归档项目的 `归档` 按钮。

## 打开条件

- 用户选择了一个未归档项目。
- 项目存在且可归档。

## 弹窗标题

`确认归档项目？`

AlertDialog 必须包含 `AlertDialogTitle`。

## 内容描述

正文应明确说明影响：

- 归档后，该项目不会再计入当前总资产、总负债和净资产。
- 项目记录仍会保留。
- 已保存的历史快照不会被重算。

正文中应展示被归档项目的关键摘要：

- 名称。
- 类型。
- 类别。
- 金额。

## 主要操作

操作按钮：

- `取消`。
- `确认归档`。

取消：

- 关闭确认框。
- 不改变数据。

确认归档：

- 调用归档 Server Action。
- 提交中禁用按钮。
- 成功后关闭确认框并刷新页面数据。

## 成功反馈

归档成功后：

- 显示 toast：`项目已归档`。
- 资产管理页汇总更新。
- 项目从默认表格中消失。

## 错误状态

- 项目不存在：显示 `项目不存在或已被归档`。
- 数据库写入失败：显示 `归档失败，请稍后重试`。
- 错误发生时确认框保持打开，用户可取消或重试。

## shadcn/ui 组件清单

- `AlertDialog`
- `Button`
- `Badge`
- `sonner`

## 移动端适配

- 按钮区域在窄屏下可上下排列。
- 摘要内容不应溢出确认框。
- 金额和名称过长时允许换行。

## 验收标准

- 点击归档按钮后显示确认框。
- 确认框展示项目名称、类型、类别和金额。
- 点击取消不会修改项目。
- 点击确认后项目被归档。
- 归档后项目不再计入当前汇总。
- 归档失败时显示错误且不关闭确认框。
