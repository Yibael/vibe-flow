# 页面 02：资产管理页

## 页面目标

资产管理页用于维护当前资产和负债项目。用户可以新增、编辑和归档项目，并查看当前资产负债汇总。

本页面是当前净值管理的主要操作页面。

## 路由建议

`/accounts`

## 用户进入方式

- 从看板页点击“管理资产”进入。
- 从顶部导航点击“资产管理”进入。

## 页面整体布局

桌面端布局从上到下为：

1. 顶部应用栏。
2. 页面标题与新增按钮。
3. 当前汇总区。
4. 筛选与搜索区。
5. 资产负债项目表格。

移动端布局为单列，表格允许横向滚动。

## 顶部应用栏

与看板页保持一致。

内容包括：

- 产品名称。
- 看板、资产管理、快照管理导航。
- 当前页面“资产管理”处于选中状态。

shadcn/ui 组件建议：

- `Button`。
- `Separator`。

## 页面标题区

内容包括：

- 主标题：`资产管理`。
- 辅助说明：`维护资产和负债余额，当前净值会根据未归档项目实时计算`。
- 主要按钮：`新增项目`。

`新增项目` 按钮点击后打开 `02-c1-account-item-modal.md`。

按钮要求：

- 使用 shadcn `Button`。
- 左侧可使用 lucide `Plus` 图标，并设置 `data-icon="inline-start"`。

## 当前汇总区

汇总区使用 3 个 Card：

1. 总资产。
2. 总负债。
3. 净资产。

展示规则：

- 汇总只包含未归档项目。
- 金额展示人民币格式。
- 净资产可以为负数。
- 没有项目时均展示 0。

shadcn/ui 组件建议：

- `Card`。
- `Badge` 可用于标识“资产”“负债”“净值”。

## 筛选与搜索区

筛选区用于快速定位项目。

控件：

- 搜索输入框：按项目名称过滤。
- 类型筛选：全部、资产、负债。
- 类别筛选：根据当前类型展示可选类别。
- 归档显示开关：默认不显示已归档项目。

交互：

- 筛选只影响当前表格展示，不修改数据。
- 搜索为空时展示全部符合筛选的项目。
- 类型切换为资产时，类别筛选只展示资产类别。
- 类型切换为负债时，类别筛选只展示负债类别。

shadcn/ui 组件建议：

- `Input`。
- `Select`。
- `ToggleGroup`。
- `Switch`，如果需要归档显示开关。

Zustand 使用：

- 可用于保存当前搜索词、类型筛选和类别筛选。
- 不保存项目列表本身。

## 项目表格

表格展示资产负债项目。

列：

- 名称。
- 类型。
- 类别。
- 金额。
- 备注。
- 更新时间。
- 状态。
- 操作。

类型列：

- 使用 `Badge` 展示“资产”或“负债”。

类别列：

- 展示中文类别名。

金额列：

- 人民币格式。
- 负债项目仍展示正数金额，不在金额前加负号。

状态列：

- 未归档：显示“有效”。
- 已归档：显示“已归档”。

操作列：

- 未归档项目展示 `编辑` 和 `归档`。
- 已归档项目不展示归档按钮；第一版不要求恢复。

交互：

- 点击 `编辑` 打开 `02-c1-account-item-modal.md`，进入编辑模式。
- 点击 `归档` 打开 `02-c2-archive-account-alert.md`。

shadcn/ui 组件建议：

- `Table`。
- `Badge`。
- `Button`。
- 可选 `DropdownMenu` 用于移动端收纳操作。

## 空状态

无项目时：

- 使用 `Empty`。
- 文案：`暂无资产负债项目`。
- 操作按钮：`新增第一个项目`。
- 点击按钮打开 `02-c1-account-item-modal.md`。

筛选后无结果时：

- 文案：`没有符合条件的项目`。
- 提供清空筛选按钮。

## 错误状态

数据读取失败时：

- 显示错误提示。
- 提供重试按钮。
- 不展示伪造汇总数据。

归档或保存失败时：

- 弹窗内或页面顶部显示错误。
- 表格数据保持原状态。

## 移动端适配

- 标题区按钮换行展示。
- 汇总 Card 单列或两列排列。
- 筛选控件纵向排列。
- 表格横向滚动。
- 操作按钮可收纳为菜单，但仍需能触达编辑和归档。

## shadcn/ui 组件清单

- `Button`
- `Card`
- `Table`
- `Badge`
- `Input`
- `Select`
- `ToggleGroup`
- `Switch`
- `Empty`
- `Separator`

## 验收标准

- 页面能展示当前资产、负债和净资产汇总。
- 用户可以从页面打开新增项目弹窗。
- 用户可以从表格打开编辑项目弹窗。
- 用户可以从表格打开归档确认框。
- 筛选和搜索不修改原始数据。
- 已归档项目默认不展示。
- 金额为 0 的项目可以正常展示。
- 移动端表格不挤压导致文字重叠。
