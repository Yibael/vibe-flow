# 子节点 02-c1：资产负债项目弹窗

## 节点类型

Dialog。

## 节点目标

用于新增或编辑资产负债项目。新增模式和编辑模式共用同一个弹窗。

## 触发来源

- 在 `docs/page/02-accounts-page.md` 点击 `新增项目`。
- 在资产负债项目表格中点击某一行的 `编辑`。
- 在空状态中点击 `新增第一个项目`。

## 打开条件

新增模式：

- 用户点击新增入口。
- 表单为空，项目类型默认选择“资产”。

编辑模式：

- 用户点击某个项目的编辑入口。
- 表单填充该项目当前数据。
- 已归档项目第一版不进入编辑模式。

## 弹窗标题

新增模式：

- 标题：`新增项目`。
- 描述：`录入一个资产或负债余额，用于计算当前净值`。

编辑模式：

- 标题：`编辑项目`。
- 描述：`更新项目名称、类别、金额或备注`。

Dialog 必须包含 `DialogTitle`。如果视觉上隐藏标题，也必须保留可访问性标题。

## 表单字段

### 项目类型

控件：

- 使用 `ToggleGroup` 或 `Select`。

选项：

- 资产。
- 负债。

规则：

- 新增模式默认资产。
- 切换类型后，类别字段重置为该类型下的第一个可选类别或空值。

### 名称

控件：

- `Input`。

规则：

- 必填。
- 去除首尾空格。
- 不能为空字符串。

占位示例：

- `招商银行储蓄卡`
- `住房贷款`

### 类别

控件：

- `Select`。

资产类别：

- 现金。
- 银行账户。
- 投资。
- 房产。
- 车辆。
- 其他资产。

负债类别：

- 贷款。
- 信用卡。
- 其他负债。

规则：

- 必填。
- 类别必须与项目类型匹配。
- 资产项目不能选择负债类别。
- 负债项目不能选择资产类别。

### 金额

控件：

- `Input`，类型可为 text 或 number。

规则：

- 必填。
- 单位为人民币元。
- 可以为 0。
- 不允许负数。
- 保存时转换为整数分。
- 展示编辑值时从分转换为元。

辅助说明：

- `请输入当前余额，负债也按正数录入`。

### 备注

控件：

- `Textarea`。

规则：

- 选填。
- 可为空。
- 用于记录账户说明，不参与计算。

## 表单布局

使用 shadcn Field 体系：

- `FieldGroup` 包裹所有字段。
- 每个字段使用 `Field`。
- 标签使用 `FieldLabel`。
- 辅助说明使用 `FieldDescription`。
- 错误信息显示在字段下方。

不得用裸 `div` 拼出表单语义。

## 主要操作

底部操作区包含：

- `取消`。
- `保存`。

保存按钮：

- 新增模式文案：`保存项目`。
- 编辑模式文案：`保存修改`。
- 提交中禁用按钮。
- 可配合 `Spinner` 显示提交状态。

取消按钮：

- 关闭弹窗。
- 不提交表单。
- 不改变数据。

## 校验反馈

字段错误：

- 名称为空：`请输入项目名称`。
- 类别为空：`请选择类别`。
- 金额为空或格式错误：`请输入有效金额`。
- 金额为负：`金额不能为负数`。

全局错误：

- 数据库保存失败时，在弹窗底部显示通用错误。
- 保存失败不关闭弹窗。

## 成功反馈

新增成功：

- 关闭弹窗。
- 页面汇总和表格刷新。
- 显示 toast：`项目已新增`。

编辑成功：

- 关闭弹窗。
- 页面汇总和表格刷新。
- 显示 toast：`项目已更新`。

## shadcn/ui 组件清单

- `Dialog`
- `Field`
- `Input`
- `Textarea`
- `Select`
- `ToggleGroup`
- `Button`
- `Spinner`
- `sonner`

## 移动端适配

- 弹窗宽度适配屏幕。
- 字段纵向排列。
- 底部按钮在窄屏下可上下排列。
- 金额输入框不能因为前缀或辅助文本导致溢出。

## 验收标准

- 新增模式打开时表单为空且默认资产类型。
- 编辑模式打开时表单正确回填。
- 切换项目类型后类别选项同步变化。
- 空名称无法保存。
- 负数金额无法保存。
- 负债金额以正数录入。
- 保存成功后弹窗关闭并刷新资产管理页数据。
- 保存失败时弹窗保持打开并显示错误。
