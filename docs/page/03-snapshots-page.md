# 页面 03：快照管理页

## 页面目标

快照管理页用于查看、保存、补录和删除净值快照。用户可以确认今日快照状态，也可以为历史日期补录快照。

## 路由建议

`/snapshots`

## 用户进入方式

- 从看板页点击“管理快照”进入。
- 从顶部导航点击“快照管理”进入。

## 页面整体布局

桌面端布局从上到下为：

1. 顶部应用栏。
2. 页面标题与补录入口。
3. 今日快照状态区。
4. 快照概览区。
5. 快照列表。

移动端布局为单列。

## 顶部应用栏

与看板页保持一致。

内容包括：

- 产品名称。
- 看板、资产管理、快照管理导航。
- 当前页面“快照管理”处于选中状态。

shadcn/ui 组件建议：

- `Button`。
- `Separator`。

## 页面标题区

内容包括：

- 主标题：`快照管理`。
- 辅助说明：`保存每日净值快照，追踪净值随时间变化`。
- 主要按钮：`补录快照`。

点击 `补录快照` 打开 `03-c1-backfill-snapshot-modal.md`。

## 今日快照状态区

该区域展示当前本地日期的快照状态。

可能状态：

1. 今日未保存快照。
2. 今日已保存快照。
3. 今日快照已根据资产变更自动更新。

内容包括：

- 今日日期。
- 今日快照状态。
- 今日总资产、总负债、净资产。
- 最后更新时间，如果今日快照存在。
- 操作按钮：`保存今日快照` 或 `更新今日快照`。

交互：

- 点击保存或更新后，基于当前未归档资产负债项目生成今日快照。
- 如果今日已经存在快照，则覆盖更新同一条快照。
- 操作成功后刷新快照列表。

shadcn/ui 组件建议：

- `Card`。
- `Badge`。
- `Button`。

## 快照概览区

概览区用于快速总结快照数据。

建议展示：

- 快照总数。
- 最新快照日期。
- 最新净资产。
- 最早快照日期。

无快照时：

- 快照总数为 0。
- 其他指标展示 `暂无`。

shadcn/ui 组件建议：

- `Card`。
- `Badge`。

## 快照列表

列表展示所有已保存快照。

默认排序：

- 按快照日期倒序。

表格列：

- 快照日期。
- 总资产。
- 总负债。
- 净资产。
- 更新时间。
- 操作。

操作列：

- `删除`。

点击删除打开 `03-c2-delete-snapshot-alert.md`。

shadcn/ui 组件建议：

- `Table`。
- `Badge`。
- `Button`。

## 空状态

无快照时：

- 使用 `Empty`。
- 文案：`暂无净值快照`。
- 辅助说明：`保存今日快照或补录历史快照后，可在看板查看趋势`。
- 操作按钮：
  - `保存今日快照`。
  - `补录历史快照`。

## 错误状态

读取失败：

- 页面展示错误提示和重试按钮。

保存今日快照失败：

- 在今日快照状态区展示错误。
- 不更新快照列表。

删除快照失败：

- 在删除确认框内展示错误。

## 移动端适配

- 标题区按钮换行展示。
- 今日快照状态 Card 内指标纵向排列。
- 快照列表允许横向滚动。
- 删除按钮不能与日期或金额重叠。

## 验收标准

- 页面能展示今日快照是否存在。
- 用户可以保存或更新今日快照。
- 用户可以打开补录快照弹窗。
- 快照列表按日期倒序展示。
- 用户可以打开删除快照确认框。
- 无快照时展示空状态。
- 保存或删除失败时有明确错误反馈。
- 移动端无文本重叠。
